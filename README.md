# Student Performance Analysis

## Project Overview
This project explores student academic performance using Python. It applies Exploratory Data Analysis (EDA) to understand how study habits, student characteristics, and other factors relate to mathematics grades.

## Dataset
- **Source:** [UCI Machine Learning Repository – Student Performance](https://archive.ics.uci.edu/dataset/320/student+performance)
- **Dataset file:** `student-mat.csv`
- **Records:** 395 students
- **Features:** 33 columns
- **Target variable:** `G3` (final mathematics grade)

The dataset contains information about students' demographic backgrounds, family circumstances, study habits, school-related factors, and academic grades.

## Tools and Technologies
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Jupyter Notebook / Google Colab

## Analysis Performed
The project includes:

1. Dataset loading and inspection
2. Data quality checks for missing values and duplicate records
3. Descriptive statistical analysis
4. Mathematics grade distribution analysis
5. Study time and final grade comparison
6. Absences and academic performance analysis
7. Gender-based grade comparison
8. Mother's education and student performance analysis
9. Correlation analysis among numerical variables

## Visualizations
The project generates the following charts:

- Final Grade Distribution
- Study Time vs Final Grade
- Absences vs Final Grade
- Gender vs Final Grade
- Mother's Education vs Final Grade
- Correlation Heatmap

## Project Files
- `Student_Performance_Analysis.ipynb` — Complete Python analysis and visualizations.
- `project_outputs.zip` — Generated charts and statistical reports in CSV format.

## How to Run
1. Download or clone this repository.
2. Download the Student Performance dataset from the UCI repository.
3. Extract the dataset and place `student-mat.csv` in the `student_data` folder.
4. Open the notebook using Google Colab or Jupyter Notebook.
5. Run the cells to reproduce the analysis.

## Project Objective
The objective is to practice data analysis skills, explore academic performance patterns, and communicate findings through statistical summaries and visualizations.
